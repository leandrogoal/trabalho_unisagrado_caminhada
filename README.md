# Caminhada PCD e Pet PCD

Página inicial responsiva desenvolvida para o módulo de Bootcamp Desenvolvimento Web Responsivo. O projeto usa como referência visual o site Caminhada PCD e Pet PCD e apresenta somente a experiência pública inicial do evento.

## Funcionalidades

- Navegação por âncoras entre as cinco seções da página.
- Menu responsivo para smartphones.
- Hero visual com imagem adaptada para telas menores.
- Apresentação do propósito, valores e programação do evento.
- Formulário demonstrativo de interesse, sem armazenamento de dados.
- Layout responsivo para desktop, tablet e smartphone.

## Tecnologias utilizadas

- HTML5 semântico
- CSS3 com Grid, Flexbox e media queries
- JavaScript puro
- PHP apenas como servidor compatível com o XAMPP

Não foram utilizados frameworks de CSS ou JavaScript.

## Como executar

1. Coloque esta pasta dentro de `C:\xampp\htdocs\php`.
2. Inicie o Apache pelo XAMPP.
3. Acesse `http://localhost/php/trabalho_unisagrado_caminhada/` no navegador.

Também é possível abrir o `index.php` diretamente em um servidor PHP local.
